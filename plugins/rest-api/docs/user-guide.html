Zonvo Platform Documentation Sept 2026

Welcome to Zonvo 👋

Zonvo ek AI-powered voice agent platform hai jo aapke calls ko automate karta hai — inbound support se lekar outbound sales campaigns tak. Ye guide aapko har feature use karna sikhayegi.

🏠

Platform Overview

Zonvo ka main kaam hai AI voice agents banana jo aapki taraf se real phone calls handle karein — bina kisi human ke. Platform ke main components:

🤖
AI Agents
Custom voice agents banao jo calls attend karein, sawal poochein, aur actions lein.
📣
Campaigns
Bulk outbound calling — hazaron contacts ko ek saath call karo.
📞
Phone Numbers
Plivo ya Twilio se real phone numbers lo. Inbound & outbound dono ke liye.
📈
Analytics
Real-time dashboards — calls, duration, conversion rate, agent performance.
🔗
Webhooks
Har call ke baad apne CRM/system ko real-time data bhejo.
🔑
REST API
Programmatically calls trigger karo aur data fetch karo.
🧰
Agent Actions
Transfer, appointment booking, lead save, callbacks, custom API lookups, voicemail handling — sab agent builder mein.
🗂️
Quick CRM
AI-scored leads, team inbox, SLA, aur Zoho / Salesforce / GoHighLevel sync.

AI Agents Banana

Agent ek virtual voice assistant hai jo aapki jagah call attend karta hai. 2 types ke agents hote hain:

🌊 Flow Agent
Visual conversation builder. Pre-defined script se chalta hai. Structured calls ke liye perfect.
📥 Incoming Agent
Inbound calls ke liye. Customer ki baat sunkar AI se response deta hai. Dynamic conversations.

Naya Agent Kaise Banayein

1
Agents Page Kholo
Left sidebar → Agents → + Create Agent button click karo.
2
Basic Info Bharo
Name: Agent ka naam (e.g. "Sales Bot"). Language: Hindi/English/Hinglish. Voice: Male ya Female voice choose karo.
3
System Prompt Likho
Ye agent ki personality define karta hai. Example:

Tum Zonvo ke sales agent ho. Customer se friendly tarike se baat karo. Unhe hamara premium plan batao aur demo book karwao.
4
Tools & Knowledge (Step 4)
Transfer, appointments, save lead, callbacks, custom API lookups, knowledge base, aur voicemail handling yahan on karo. Details neeche Tools & Voicemail mein.
5
WhatsApp & Email (Step 5) → Save → Test
Agent ko templates bhejne do aur owner alerts set karo. Save ke baad Test in browser se mic pe baat karke check karo, phir phone number attach karo.
System prompt likhte waqt simple, conversational language use karo. Hindi ya Hinglish mein likho agar Indian customers ke liye hai.

Call Outcomes & Smart Retry

Har khatam hui call ka ek outcome hota hai. Agent baat-cheet ke end mein khud set karta hai, ya platform telephony events se set karta hai.

OutcomeKaun set karta haiMatlab
InterestedAgentCustomer aage badhna chahta hai — lead hot
Callback requestedAgentBaad mein call karne ko kaha — callback auto-schedule hota hai
Not interested / No decision / Already a customer / Wrong numberAgentFinal outcomes — campaign dobara dial nahi karti
Do not callAgentCustomer ne mana kiya — number DND list mein chala gaya
No answer / Busy / Failed / VoicemailSystemRetry rules ke hisaab se dobara try hota hai
Appointment booked / TransferredSystemAgent ne booking ki ya call human ko transfer hui

Campaign Smart Retry Kaise Set Karein

1
Build → Campaigns → + Create Campaign
Campaign details bharne ke baad Auto-retry missed calls section kholo.
2
Har Outcome Ke Liye Rule
No answer, Busy, Call failed, Voicemail — har ek ke liye alag Wait (minutes) (5 se 10,080) aur Max calls (0–10, pehli call included) set karo.
3
Outcome Filter Se Track Karo
Monitor → Calls → Outcome filter, ya Analytics → Insights → Outcome breakdown.
Interested, Not interested, Wrong number, Already a customer, Do not call aur Appointment booked final hain — in par kabhi retry nahi hota.

Callbacks

Jab customer kehta hai "kal 11 baje call karna", agent callback schedule kar deta hai aur platform us time pe automatically call karta hai. Aap manually bhi schedule kar sakte ho.

1
Agent Mein On Karo
Build → Agents → agent kholo → Step 4 Tools & knowledge → Schedule a callback toggle. "At most … days ahead" set karo (default 7, max 60).
2
Monitor → Callbacks
Sidebar → Monitor → Callbacks. Har callback ka Contact, When, Reason, Agent aur status dikhta hai: Pending Calling Called Failed Cancelled.
3
Manually Schedule Karo
Schedule a callback button → Agent (sirf Plivo/Sarvam agents), Phone number, Name, When (aapka local time), Reason (agent ko sunai deta hai) → Schedule. Pending callback ko cancel bhi kar sakte ho.
Called callback ki row se seedha result call khulti hai — outcome aur transcript wahin dekho. CRM se bulk callbacks (variables ke saath) REST API se schedule karo: POST /api/v1/callbacks/bulk.

Do-not-call List

Jo numbers kabhi dial nahi hone chahiye. Campaigns, API calls aur callbacks — sab is list ko respect karte hain.

1
All Contacts → Do not call
Sidebar → Telephony → All Contacts → Do not call tab. Yahan blocked numbers, reason (caller request / manual / import / complaint) aur source (agent / manual / upload / api) dikhte hain.
2
Number Add Ya Upload Karo
Ek number note ke saath add karo, ya list upload karo. 10-digit number automatically +91 ban jaata hai.
3
Agent Khud Add Karta Hai
Call pe customer kahe "dobara call mat karna" / "unsubscribe" — agent number list mein daal deta hai, ek line mein confirm karta hai, aur call end karta hai. Call ka outcome Do not call ban jaata hai.
Galti se add hua number list se remove karo — warna us number pe koi campaign ya callback nahi jayegi.

Appointments & Availability

Agent free slots check karke customer ke liye appointment book karta hai — aapke calendar ke hisaab se.

1
Agent Mein "Book appointments" On Karo
Build → Agents → Step 4 Tools & knowledge → Book appointments. Set karo: Slot length (default 30 min), Time zone (Asia/Kolkata), Working hours (09:00–18:00), Working days, Service name, aur Send a confirmation after booking (WhatsApp / Email — Step 5 mein enable hona chahiye).
2
Calendar Connect Karo (Optional)
Flow Builder → Appointments mein Google Calendar connect karo, ya Build → Tools → Integrations mein Cal.com / GoHighLevel calendar. Tab agent sirf sach-much free slots offer karta hai aur booking calendar mein bhi banti hai.
3
Appointments Dekho & Update Karo
Flow Builder → Appointments (dashboard ke appointments card se bhi). Status: scheduled → confirmed / cancelled / completed / no-show. Lead pe bhi Appointment Booked stage lag jaata hai.
Agent pehle check_availability karta hai, 2–3 slots offer karta hai, naam-date-time confirm karke book karta hai. Owner alert "Appointment booked" trigger se turant email/WhatsApp lo.

Save Lead & CRM Inbox

Agent call pe customer ka naam, phone, email aur aapke custom fields collect karke Quick CRM mein lead banata hai — AI score, summary aur next action ke saath.

1
"Save the caller as a lead" On Karo
Build → Agents → Step 4 Tools & knowledge → Save the caller as a lead. Extra fields add karo (e.g. Budget, City) aur required mark karo — agent unhe zaroor poochhega.
2
Manage → Quick CRM
Kanban ya list view mein leads: stage (New Lead, Hot Lead, Appointment Booked, Form Submitted, Needs Follow-up, Not Interested, No Answer), lead score, sentiment, tags. Lead kholo → recording, AI summary, transcript, notes aur activity.
3
Team Inbox — Assignment
Quick CRM → Team Inbox view. Filters: Mine / Unassigned / Overdue / All. Har lead ko team member assign karo (row se ya bulk assign), notes add karo.
4
SLA & Auto-assign
SLA & auto-assign button → Auto-assign new leads: Off ya Round-robin across active team members. SLA per stage (hours) aur default SLA (48 h). Jis lead pe SLA ke andar koi update/note nahi hua, wo Overdue mein dikhti hai; note add karne se clock reset hota hai.
Saved leads automatically connected CRM (Zoho, Salesforce, GoHighLevel) mein sync hoti hain aur lead.upserted webhook fire hota hai. REST API: GET /api/v1/leads, PATCH /api/v1/leads/:id.

WhatsApp Inbound Auto-reply

1
Messaging → WhatsApp → Auto-reply

2
Webhook URL Waki Mein Daalo

Conversations Mein Dekho

Call Quality Score

Transcript wali har completed call kuch minutes mein automatically score hoti hai (10 mein se).

1
Monitor → Calls → Call Kholo
Call detail mein Call quality card: overall score, sub-scores — Greeting, Understanding, Objection handling, Prompt compliance, Closing.
2
Strengths, Improvements, Flags

Re-score
