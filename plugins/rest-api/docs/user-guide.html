Zonvo Platform Documentation v5.4

Welcome to Zonvo 👋

Zonvo ek AI-powered voice agent platform hai jo aapke calls ko automate karta hai — inbound support se lekar outbound sales campaigns tak. Ye guide aapko har feature use karna sikhayegi.

🏠

Platform Overview

Zonvo ka main kaam hai AI voice agents banana jo aapki taraf se real phone calls handle karein — bina kisi human ke. Platform ke main components:

🤖
AI Agents
Custom voice agents banao jo calls attend karein, sawal poochein, aur actions lein.
📣
Campaigns
Bulk outbound calling — hazaron contacts ko ek saath call karo.
📞
Phone Numbers
Plivo ya Twilio se real phone numbers lo. Inbound & outbound dono ke liye.
📈
Analytics
Real-time dashboards — calls, duration, conversion rate, agent performance.
🔗
Webhooks
Har call ke baad apne CRM/system ko real-time data bhejo.
🔑
REST API
Programmatically calls trigger karo aur data fetch karo.
👤

Account Setup

Zonvo use karna shuru karne ke liye ye steps follow karo:

1
Register / Login
app.zonvo.tech par jaao → Sign Up button click karo → Email + password dalo → Email verify karo.
2
Profile Complete Karo
Settings → Profile mein jaao. Apna naam, company name, aur time zone set karo.
3
Plan Select Karo
Settings → Billing mein jaao. Free trial se shuru karo ya apni zaroorat ke hisaab se plan choose karo.
4
Pehla Agent Banao
Dashboard → Agents → + New Agent. Agent ka naam, voice, aur system prompt set karo.

AI Agents Banana

Agent ek virtual voice assistant hai jo aapki jagah call attend karta hai. 2 types ke agents hote hain:

🌊 Flow Agent
Visual conversation builder. Pre-defined script se chalta hai. Structured calls ke liye perfect.
📥 Incoming Agent
Inbound calls ke liye. Customer ki baat sunkar AI se response deta hai. Dynamic conversations.

Naya Agent Kaise Banayein

1
Agents Page Kholo
Left sidebar → Agents → + Create Agent button click karo.
2
Basic Info Bharo
Name: Agent ka naam (e.g. "Sales Bot"). Language: Hindi/English/Hinglish. Voice: Male ya Female voice choose karo.
3
System Prompt Likho
Ye agent ki personality define karta hai. Example:

Tum Zonvo ke sales agent ho. Customer se friendly tarike se baat karo. Unhe hamara premium plan batao aur demo book karwao.
4
Telephony Provider Set Karo
Plivo (Indian numbers) ya Twilio (international) choose karo. Phone number assign karo.
5
Test & Publish
Test Call button se pehle test karo. Sab theek lage toh Publish karo.
System prompt likhte waqt simple, conversational language use karo. Hindi ya Hinglish mein likho agar Indian customers ke liye hai.

Agent Best Practices

Kya KaroKya Na Karo
Short, clear sentencesLambe paragraphs mat likho
Agent ka ek naam do (e.g. "Main Priya hoon")Bahut zyada formal/sarkari language mat use karo
Specific tasks define karoAgent ko sab kuch karne ko mat kaho
Fallback response set karoEdge cases ignore mat karo

Phone Numbers

Agents ke liye real phone numbers chahiye hote hain. Zonvo 2 providers support karta hai:

🇮🇳 Plivo (India)
Indian numbers ke liye best. Local +91 numbers milte hain. Cost-effective. Sarvam AI voice engine support karta hai.
🌍 Twilio (International)
Global numbers ke liye. USA, UK, Australia etc. ElevenLabs voice engine ke saath kaam karta hai.

Phone Number Kaise Lein

1
Phone Numbers Page Kholo
Sidebar → Phone Numbers. Yahan aapke existing numbers dikhenge.
2
Provider Tab Choose Karo
Plivo tab click karo Indian numbers ke liye. Twilio tab international ke liye.
3
Number Search Karo
Country → State → City filter karo. Available numbers ki list aayegi.
4
Number Purchase Karo
Buy button click karo. Number turant aapke account mein aa jayega.
5
Agent Se Link Karo
Agent settings mein jaao → Phone Number dropdown → apna number select karo.
📣

Campaigns (Bulk Calling)

Campaign ek automated bulk calling operation hai jismein ek hi agent hazaron contacts ko call karta hai.

Campaign Kaise Banayein

1
Campaigns → New Campaign
Sidebar → Campaigns → + Create Campaign.
2
Campaign Details
Name: Campaign ka naam. Agent: Kaunsa agent use hoga. Phone Number: Kaunse number se calls jayengi.
3
Contacts Add Karo
CSV file upload karo ya existing contact list select karo. Format: name, phone, email (first row headers).
4
Schedule Set Karo (Optional)
Calls abhi start karni hain ya baad mein? Time aur date set karo. Calling hours set karo (e.g. 9 AM – 6 PM).
5
Campaign Launch Karo
Start Campaign click karo. Dashboard pe real-time progress dikhega.

Campaign Status

StatusMatlab
ScheduledStart hone ka wait kar raha hai
RunningCalls chal rahi hain
CompletedSaare contacts call ho gaye
PausedManually rokha gaya
CSV file mein international format mein phone numbers daalo: +919999988888 (country code ke saath).

Webhooks

Webhooks se Zonvo aapke CRM, database ya kisi bhi system ko real-time events bhej sakta hai.

Webhook Kaise Setup Karein

1
Settings → Webhooks
Sidebar → Settings → Webhooks tab.
2
New Webhook Add Karo
URL: Apne server ka endpoint dalo (e.g. https://yourapp.com/webhook/zonvo).
Events: Kaun se events sunna chahte ho.
3
Test Karo
Send Test Payload button click karo. Apne server pe receive hota dekho.

Available Events

EventKab Fire Hota Hai
call.startedCall connect hone par
call.completedCall khatam hone par (with transcript)
call.failedCall fail hone par
campaign.startedCampaign start hone par
campaign.completedCampaign finish hone par

Sample Webhook Payload

{
  "event": "call.completed",
  "call_id": "cl_xyz123",
  "agent_id": "ag_abc456",
  "contact": { "name": "Rahul", "phone": "+919876543210" },
  "duration": 142,
  "status": "completed",
  "transcript": "Agent: Namaste Rahul ji...",
  "summary": "Customer interested in premium plan",
  "timestamp": "2025-06-25T10:30:00Z"
}

API Keys

REST API use karne ke liye aapko API key chahiye hogi.

1
Settings → Developer
Sidebar → Settings → Developer tab kholo.
2
New API Key Generate Karo
Generate API Key button click karo. Key ka naam do (e.g. "My CRM Integration").
3
Key Copy Karo (Sirf Ek Baar Dikhegi!)
Key copy karo aur safely store karo. Baad mein dobara nahi dikhegi.
4
API Use Karo
Har request mein header mein bhejo: Authorization: Bearer YOUR_API_KEY
API key ko kabhi bhi public GitHub, frontend code, ya kisi aur ke saath share mat karo.

Troubleshooting

Common Problems

ProblemSolution
Call connect nahi ho rahaPhone number agent se linked hai? Telephony provider credentials check karo Settings mein.
Agent Hindi mein nahi bol rahaAgent settings mein Language "Hindi" ya "Hinglish" select karo. Sarvam AI voice use karo.
Campaign calls fail ho rahe hainContact list mein phone numbers format check karo: +91XXXXXXXXXX hona chahiye.
Webhook receive nahi ho rahaURL correct hai? Server publicly accessible hai? HTTPS use karo.
Credits khatam ho gayeSettings → Billing → Add Credits.
API 401 Unauthorized errorAPI key expire toh nahi hui? Nayi key generate karo Settings → Developer mein.
Koi aur problem? info@aiclex.in pe email karo ya +91 84494 88090 pe call karo. Hum 24 ghante mein response denge.
